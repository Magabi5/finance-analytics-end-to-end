# Finance Analytics End-to-End | Case Nexa

Projeto de mentoria em análise financeira com dados sintéticos da Nexa Serviços Corporativos.
Análise de orçamento versus realizado, despesas, resultado gerencial e rentabilidade por unidade e serviço.
Pipeline RAW → Trusted → Refined com SQL e Databricks, modelo dimensional e dashboard no Power BI.
